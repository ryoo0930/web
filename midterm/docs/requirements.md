# 요구사항 기준

작업 폴더에서 확인한 원본은 `../prompt.txt`뿐이다. `중간고사_2026.pdf`와 `붙여넣은 텍스트(1)(3).txt`는 제공되지 않았다. 아래는 prompt에 적힌 요약을 기준으로 하며 PDF 원문의 역할 설명, 제출 경로, 보고서 형식과 날짜/요일은 대조가 필요하다. 제출기한을 추정하지 않으며 원격 제출하지 않는다.

| 구분 | 요구사항 |
|---|---|
| FR-01~06 | 구성원 등록·조회·역할·상태, Crew 책임자와 단일 정식 소속 및 편성 |
| FR-07~12 | 업무 CRUD·일정·우선순위·복수 참여·상태 이력·완료 결과·조건 검색 |
| FR-13~17 | 공용 자원, 가용 상태, 예약·인수·반환·점검, 사용 이력 |
| FR-18~20 | 완료 활동 평가, 평가 정정 이력, 활동·관리 감사 |
| FR-21~23 | 범위 제한 검색, 기간/Crew 운영 집계, 계정·권한 관리 |
| BR-01~03 | 단일 정식 소속, 정지/탈퇴 배정 거부, 반열린 시간 구간의 배타적 배정 충돌 거부 |
| BR-04~06 | 상위 역할 변경 금지, 담당 Crew 범위 제한, 종료 업무 일반 수정 금지 |
| BR-07~10 | 예약 충돌 거부, 불가 자원 배정 거부, 서버 권한 검사, 주요 변경 이력 보존 |
| DR-01~06 | 관계 일관성, 업무 참여, 현재 자원/이력, 증가하는 기록, 실제 SQL/MongoDB 분담, 학번 DB |
| AR-01~08 | REST 의미, 입력 위치, 필터·페이지, 오류 처리, 일관 응답, 200 이상 유효 API, 의미 중복 제외, 요구사항 연결 |
| NFR-01~05 | 사용자 성공/실패 안내, 예외 처리, 서버 권한, 탐색, 응답 일관성 |
| CR-01~06 | Node/Express, EJS, SQL/MongoDB, Swagger, 책임 분리, Ubuntu node app.js |

공통 요구사항은 추적표에서 `COMMON`으로, 각 API의 기능 요구사항은 `FUNCTIONAL`로 구분한다. 등록 API 계수는 채점자가 인정하는 기능 수와 같지 않다. 확장 기능(교육, 적응 계획, 회의, 자격, 위험, 산출물 등)은 관련 FR을 지원하기 위한 추가 설계다.
